# Vue 3D 俄罗斯方块

一个使用 Vue 3 + TypeScript 开发的现代化俄罗斯方块游戏，具有炫酷的 3D 效果。

## 特性

- 🎮 经典的俄罗斯方块玩法
- 🎨 现代化的 3D 界面设计
- 🎯 三个难度级别（简单、中等、困难）
- 📱 响应式设计，支持各种设备
- 🎵 流畅的动画效果
- ⌨️ 键盘控制支持

## 在线体验

访问 [https://andydenost.github.io/RussiaSquare](https://andydenost.github.io/RussiaSquare) 即可开始游戏！

## 本地开发

1. 克隆项目
```bash
git clone https://github.com/andydenost/RussiaSquare.git
cd RussiaSquare
```

2. 安装依赖
```bash
npm install
```

3. 启动开发服务器
```bash
npm run dev
```

4. 构建生产版本
```bash
npm run build
```

## 操作说明

- ↑ 旋转方块
- ← 左移
- → 右移
- ↓ 加速下落
- 空格键 暂停/继续
- R 重新开始

## 技术栈

- Vue 3
- TypeScript
- Vite
- CSS 3D Transforms
- Composition API
